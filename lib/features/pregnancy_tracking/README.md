# Pregnancy Tracking Feature

This module contains the logic, state management, and UI for the pregnancy tracking feature.
It follows a clean architecture pattern with separated data, domain (models), and presentation (screens/widgets) layers.

## Structure
- `data/`: Repositories and local/remote data sources.
- `models/`: Domain entities representing pregnancy progress.
- `providers/`: State management logic for the feature.
- `screens/`: Main UI screens.
- `widgets/`: Reusable UI components specific to this feature.
- `services/`: Specific services handling pregnancy logic.
- `utils/`: Helper functions and formatters.
