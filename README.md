# Ayla - Open Source Core

Welcome to the open-source release of the Ayla app's core tracking logic, published specifically for our award nomination submission! 

This repository showcases the `pregnancy_tracking` feature, demonstrating our approach to state management, clean architecture, and dynamic Flutter UI design.

### Directory Structure
* `lib/features/pregnancy_tracking/`: The complete feature module, containing our custom UI components, domain models, and business logic for tracking a pregnancy journey.
* Note: Surrounding boilerplate, assets, and proprietary backend services have been removed to keep the focus strictly on our core tracking architecture.
